Privacy Policy

Last updated: October 27, 2026

This policy covers "Laurestel Review Replies", an internal tool run by Laurestel LLC. It answers Google reviews for the restaurants whose Google Business Profiles Laurestel manages.

What the tool accesses

With the profile manager's permission, the tool uses the Google Business Profile API to read the profiles Laurestel manages and their public reviews (reviewer display name, star rating, review text and date), and to post owner replies to those reviews.

How the data is used

Review text is used only to write a reply to that review and to tell Laurestel when a review is negative. Replies are written on Laurestel's own computer. Review data is not sent to any third-party service.

What is stored

The tool keeps a local log and a record of which reviews it has handled, on Laurestel's own computer. It does not sell, rent or share Google user data, and does not use it for advertising.

Google API Services

Laurestel Review Replies' use and transfer of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time from the Google Account permissions page: myaccount.google.com/permissions.
